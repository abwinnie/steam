# 櫻花泡沫實驗室 Sakura Lab

繁體中文大象牙膏 3D 教學模擬遊戲。使用 Three.js 與 Vite，可調整 H₂O₂ 濃度、選擇添加物／催化劑及 RGB 色彩，旋轉觀察附底座與刻度的透明 100 mL 量筒、噴發、液面下降與持續堆積的泡沫。

## 開發

需要 Node.js 22.12 以上。

```sh
npm ci
npm run dev
```

`npm run build` 產生 `dist/`；`npm run preview` 在本機驗證正式版本。依賴由 npm 安裝，不依賴執行階段 Three.js CDN。

## GitHub Pages

將檔案提交並推送至 `abwinnie/steam` 的 `main` 分支。在 GitHub 儲存庫 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。內附 `.github/workflows/pages.yml` 會建置與部署，之後每次推送 main 自動更新。若第一次推送前尚未啟用 Pages，啟用後到 Actions 重新執行 workflow。

只有部署成功後，預期網址 `https://abwinnie.github.io/steam/` 才可使用；網址本身不代表已上線。需確認儲存庫與 Pages 的存取設定允許公開讀取。

## 模型與限制

- 固定假設 100 mL 過氧化氫溶液，密度 1.11 g/mL，另加 10 g 催化劑／皂液。H₂O₂ 百分比視為質量分率。
- 化學計量：`2 H₂O₂ → 2 H₂O + O₂`；以 24 L/mol、55% 氧氣捕捉率估算泡沫體積。重量以反應前溶液總質量減去釋放氧氣估算，不表示全部重量都會離開燒瓶。
- KI 濃度或其他催化劑的相對添加量只改變示意反應速率／噴發形態，不增加氧氣的理論產量；H₂O₂ 濃度或添加量為 0 時不噴發。其他添加量的百分比為遊戲相對值，不是實際濃度或克數。
- RGB 為光色混合，並非真實染料混色。泡沫使用具孔隙貼圖的重疊實例粒子、重力、徑向擾動、碰撞與高度格堆積，是即時視覺近似，不是數值流體力學。
- 體積與重量是教學估算；不是實驗預測。尤其高濃度數值僅供虛擬遊玩，請勿依此進行實際操作。

## 添加物／催化劑

提供 KI、MnO₂、KMnO₄、酵母菌、FeCl₃、FeCl₂、NaCl、MgSO₄、CuSO₄、Fe₂(SO₄)₃ 共 10 種選擇。

- MnO₂ 為二氧化錳；過錳酸鉀為 KMnO₄，兩者分開列出。KMnO₄ 涉及不同氧化還原反應，沒有沿用催化分解模型，因此顯示「尚未建立反應模型」，不預測其噴發或產量。
- NaCl 與 MgSO₄ 在此簡化模型作為沒有明顯催化效果的比較組，不噴發。這不是宣稱其在所有化學條件下完全不反應。
- 其餘添加物使用自訂的遊戲速度參數；FeCl₃ < FeCl₂、CuSO₄ < MnO₂ < Fe₂(SO₄)₃ 的示意速度依使用者比較需求設定，不是實測常數或通用排序。實際反應與酸鹼度、溫度、粒徑及配方有關。
- 酵母選項顯示使用者提供的「10 g 酵母＋11 mL 熱水」備註；未模擬溫度、酵素失活、此用量的活性或額外質量。
- 使用者已確認「0/1–0.3 g、30% 0.1–0.3 mL H₂O₂」只作比較備註；介面保留原始記錄，不新增用量輸入，也不參與質量或體積計算。體積／重量仍使用上面的固定教學模型，不能視為各添加物配方的實測產出。

執行 `npm test` 驗證選項、零值、比較組、速度參數及氧氣產量模型。
